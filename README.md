# Gestão de Tarefas

Este projeto é uma aplicação web desenvolvida em **React** para ajudar na organização de tarefas.  
O sistema permite cadastrar, editar, excluir e marcar tarefas como concluídas, além de apresentar um layout estilizado com cards.

---

## Funcionalidades
- Adicionar novas tarefas com título, prazo e responsável.
- Editar tarefas já cadastradas.
- Excluir tarefas.
- Marcar tarefas como concluídas.
- Visualização em cards estilizados com cores e ícones.
- Responsividade para funcionar em diferentes tamanhos de tela.

---

## Tecnologias utilizadas
- **React** (biblioteca principal)
- **JavaScript**
- **CSS** (para estilização)
- **React Icons** (para ícones de edição, exclusão e conclusão)

## Como executar o projeto
1. Clone este repositório:
git clone https://github.com/SilvaDaiane-dot/gestao-tarefas.git (github.com in Bing)
2. Entre na pasta do projeto:
cd gestao-tarefas
3. Instale as dependências:
npm install
4. Inicie o servidor de desenvolvimento:
npm start
5. Abra o navegador e acesse:
http://localhost:3000
